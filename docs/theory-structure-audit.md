## 적용 기준

- 학습 화면의 목차를 `능력단위 → 능력단위 요소 → 필요지식 주제` 구조로 구성했다.
- 필요지식 주제마다 개념 설명과 작동 원리를 분리해 두 개 이상의 문단으로 제공한다.
- 용어는 하나의 제목에 여러 정의를 섞지 않고 개별 카드로 나누었다.
- 용어 카드에는 정의와 유사 개념과의 구분을 함께 기록했다.
- 표로 비교하는 편이 명확한 개념은 비교표를 유지하고, 실제 상황을 이해하는 데 필요한 예시는 별도 영역으로 제공한다.
- 600문항의 ID를 필요지식 주제에 연결하고, 다른 능력단위 문항이 잘못 연결되지 않았는지 검사한다.
- 각 능력단위는 해당 능력단위의 60문항 전체와 연결된다.

세부 수치와 미연결·오연결 목록은 `theory-question-coverage-audit.json`에서 확인할 수 있다. 현재 미연결 문항, 잘못된 문항 ID, 다른 능력단위로의 교차 연결, 사용되지 않은 이론 원본은 모두 0건이다.
